Colour-managed viewing without the workaround.

ZURA OCIO Look exposes an OpenColorIO 2 display/look transform as an After Effects effect, so the same display pipeline used across CG and VFX tools can live directly in the comp.

OCIO 2 processing

Modern OpenColorIO transforms with configuration-driven behaviour.

Display · View · Look

Expose the artist-facing choices that matter when matching a studio viewing pipeline.

GPU path

Designed with GPU rendering support and explicit error reporting when GPU processing is unavailable.

Made for CG/VFX review chains.

Match other DCCs

Use the same OCIO config and viewing choices as Blender, Houdini, Nuke or Resolve.

Config-driven menus

Available Displays, Views and Looks come from the OCIO configuration you load.

$OCIO aware

Works with the conventional OCIO environment-variable workflow as well as selected configurations.

Important: this is a viewing/look transform tool. It does not automatically determine the correct input colour space for every source, and it is not a substitute for a correctly designed colour pipeline.

Simple Windows install.

Download `ZURA OCIO_Look.aex`
The current public build is a Windows After Effects plug-in.
Copy it into an After Effects plug-ins location
Use your AE version's Support Files\Plug-ins folder or an appropriate shared Adobe MediaCore location.
Restart AE and add the effect
Load your OCIO config, then choose Display, View and Look from the effect controls.
